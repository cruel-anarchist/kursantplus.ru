# Курсант +

Сайт-визитка для автошколы `Курсант +` на `Astro` с подготовленной архитектурой под:

- главную продающую страницу,
- официальный раздел `Сведения об образовательной организации`,
- каталог документов,
- фирменные изображения, паттерны и иконки,
- будущее расширение услуг и контента.

## Структура

```text
public/
  documents/                будущие PDF, JPG, ZIP и сканы
  icons/                    готовые SVG-иконки
  images/
    brand/                  логотипы и брендовые изображения
    graphics/               декоративные SVG и hero-графика
    patterns/               фоновые паттерны

src/
  components/               секции, карточки, таблицы, хедер/футер
  data/                     контент и настройки сайта
  layouts/                  базовые шаблоны страниц
  pages/                    маршруты сайта
  styles/                   глобальные стили и дизайн-система
```

## Что уже готово

- Главная страница с брендовой системой.
- Отдельная страница официальных сведений.
- Оптимизированные брендовые изображения и WebP-ассеты для продакшн-сборки.
- Векторные иконки и фоновые SVG.
- Подготовленные точки для заполнения юридических данных.
- Контентный модуль под будущую услугу обновления навыков вождения.

## Что осталось добавить

1. Реальные реквизиты, контакты и адреса.
2. Документы из приложений ТЗ в `public/documents/`.
3. Точное наполнение тарифов и часов обучения.
4. Дополнительную услугу по обновлению навыков вождения.

## Команды

```bash
npm install
npm run dev
```

Если `npm install` не проходит из-за переполненного системного диска `C:`, запускайте с временными каталогами на диске `F:`:

```powershell
$env:TEMP='F:\temp'
$env:TMP='F:\temp'
$env:npm_config_cache='F:\temp\npm-cache'
npm install
```
