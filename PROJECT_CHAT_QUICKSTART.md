# PROJECT CHAT QUICKSTART

## 20-секундная шпаргалка

- Проект: сайт автошколы `Курсант +`
- Стек: `Astro`, статическая сборка
- Главная страница: `src/pages/index.astro`
- Отдельная страница сведений: `src/pages/info.astro`
- Политика конфиденциальности: `src/pages/privacy.astro`
- Глобальные стили: `src/styles/global.css`
- Контент в основном лежит в `src/data/*.ts`
- Деплой: `GitHub Pages` через `GitHub Actions`
- Форма: frontend отправляет данные на `https://api.kursantplus.ru/form-handler.php`

## Где что менять

- Контакты, соцсети, мета, hero-данные:
  `src/data/site.ts`
- Программы, тарифы, этапы, форматы:
  `src/data/programs.ts`
- Допуслуги, автопарк, документы, финансы:
  `src/data/services.ts`
- Сведения:
  `src/data/legal.ts`
- Политика конфиденциальности:
  `src/data/privacy.ts`

## Как устроен проект

- Это не React-приложение.
- Основная логика сайта: `Astro + HTML + CSS + немного inline JS`.
- Лучше менять данные в `src/data`, а не хардкодить текст в секциях.
- `dist/` не редактировать: это результат сборки.
- `public/` — только статика.

## Правила по верстке

- Использовать существующие секции и компоненты, если они уже есть.
- Новые ручные правки файлов делать аккуратно и консистентно с текущим стилем.
- Основная визуальная система живёт в `src/styles/global.css`.
- Для новых похожих интерактивных секций держать одинаковые отступы и ритм.
- Для локальных правок не плодить лишние CSS-файлы без необходимости.

## Правила по JS

- JS тут точечный, в основном inline внутри `Astro`.
- Добавлять только то, что реально нужно для интерфейса.
- Не превращать страницу в тяжёлое SPA-поведение.

## Важные текущие особенности

- Сейчас активна временная линейка графики `-two`.
- Основная форма на главной больше не должна зависеть от внешних form-handler сервисов.
- Отправка идёт на отдельный `PHP` backend `api.kursantplus.ru`.
- Реальные секреты backend в git не хранить.

## Локальная работа

- Запуск dev-сервера:
  `npm run dev -- --host 0.0.0.0 --port 4321`
- Проверка сборки:
  `npm run build`

## GitHub Pages

- Pages деплоится через workflow из `.github/workflows/deploy-pages.yml`
- После нужных изменений:
  `git add .`
  `git commit -m "..." `
  `git push origin main`

## Что проверить перед завершением

- Сайт открывается на `http://localhost:4321`
- `npm run build` проходит
- Нет ли случайных правок в `dist/`
- Если меняли тексты/формы/юридические блоки — проверить соответствующие страницы руками
